Each protocol lists the sequences in the order you run them, with links to how each view is planned. Every exam starts with the same localizers, listed first. At the scanner, open the [exam flow](/flow/) to tick the steps off as you go, with a clock that starts when you inject contrast.

The order here runs the cines before contrast. Sites differ: some give contrast earlier and run the cines while they wait for LGE. Follow your department's protocol.

# Every exam starts with

1. 3-plane localizer
2. Axial bright-blood stack of the chest
3. Axial dark-blood stack of the chest
4. Heart scouts

# Cardiomyopathy

**Before contrast**

1. Cine [2-chamber](/guide/lv-2-chamber/), [3-chamber](/guide/lv-3-chamber/) and [4-chamber](/guide/lv-4-chamber/)
2. Cine [short-axis stack](/guide/lv-short-axis/), base to apex
3. Cine 4-chamber stack
4. T1 map: [short-axis samples](/guide/lv-short-axis-samples/) (base, mid, apex). See [MOLLI maps](/guide/molli-maps/).
5. T2 map: short-axis samples

**Contrast**

1. Perfusion: short-axis samples, during the contrast injection

**After contrast**

1. TI scout, 10 minutes after contrast. See [choosing the TI time](/guide/psir-ti-time/).
2. LGE PSIR: 2-, 3- and 4-chamber
3. LGE PSIR: short-axis stack
4. LGE PSIR: 4-chamber stack
