Every abbreviation used in these guides, A to Z. In the app you can also type an abbreviation into **Search** to see what it means at the top of the results.

# Numbers

| Abbreviation | Stands for | Notes |
|---|---|---|
| 2ch, 3ch, 4ch | Two-, three- and four-chamber views | Long-axis views named for the number of chambers they show. |

# A

| Abbreviation | Stands for | Notes |
|---|---|---|
| AA | Ascending aorta | |
| ACC | American College of Cardiology | |
| AFib | Atrial fibrillation | An irregular rhythm that makes ECG gating harder. |
| AHA | American Heart Association | Also the AHA 17-segment model of the LV. |
| AL | Anterolateral wall | On labelled images: the AHA name for the LV wall opposite the septum in the 4-chamber. Elsewhere AL often means light-chain (AL) amyloidosis. |
| AN | Annulus | The fibrous ring a valve sits in. |
| APM | Anterior papillary muscle | Also called the anterolateral papillary muscle. |
| ARVC | Arrhythmogenic right ventricular cardiomyopathy | Now often called arrhythmogenic cardiomyopathy, since it can involve the LV too. |
| AS | Anteroseptal wall | On labelled images. Elsewhere often aortic stenosis. |
| ASD | Atrial septal defect | |
| AV | Aortic valve | |
| AW | Anterior wall | |

# B

| Abbreviation | Stands for | Notes |
|---|---|---|
| bSSFP | Balanced steady-state free precession | The bright-blood cine sequence. Siemens calls it TrueFISP, GE FIESTA and Philips balanced FFE. |

# C

| Abbreviation | Stands for | Notes |
|---|---|---|
| CINE | Cine imaging | Not really an abbreviation: a movie of the heart through the cardiac cycle. |
| CMR | Cardiovascular magnetic resonance | Another name for cardiac MRI. |
| CS | Compressed sensing | Acquires less data and still reconstructs the image, for shorter breath-holds. |

# E

| Abbreviation | Stands for | Notes |
|---|---|---|
| ECG | Electrocardiogram | Used to gate (time) the images to the heartbeat. |
| ECV | Extracellular volume | Calculated from T1 maps before and after contrast, plus the hematocrit. |
| EDV | End-diastolic volume | The ventricle's volume when it's fullest. |
| EF | Ejection fraction | Stroke volume divided by EDV, as a percentage. |
| EGE | Early gadolinium enhancement | Images in the first few minutes after contrast, mainly to look for thrombus and MVO. |
| ESC | European Society of Cardiology | |
| ESV | End-systolic volume | The ventricle's volume at the end of contraction. |

# T

| Abbreviation | Stands for | Notes |
|---|---|---|
| T1, T2 | T1 and T2 relaxation times | The tissue properties that mapping sequences measure. |
| T2* | T2-star | Measures iron in the heart and liver. Run it before contrast. |
| TAVI | Transcatheter aortic valve implantation | Also called TAVR. |
| TI | Inversion time | The delay after the inversion pulse, set so normal myocardium is black on LGE. |
| TrueFISP | True fast imaging with steady-state precession | Siemens' name for bSSFP. |
| TSE | Turbo spin echo | Siemens' and Philips' name for FSE. |
| TV | Tricuspid valve | |
